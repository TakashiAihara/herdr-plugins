# herdr-plugins

Plugins for [Herdr](https://herdr.dev). Each directory is one plugin; install only the ones you need.

```bash
herdr plugin install TakashiAihara/herdr-plugins/<plugin>
```

| Plugin | What it does |
|---|---|
| [claude-dev-channels-accept](claude-dev-channels-accept/) | Answers Claude Code's development-channels warning so `claude` starts without a wrapper |
